# 📸 Clinic & Doctor Photos Placement Guide

Welcome to the **Oracare Dental Clinic** image directory. 
The website is programmed with **smart automatic fallback**:
- If your real photos are present here, the website will display them immediately.
- If a photo is missing, it will gracefully display an elegant medical SVG illustration/badge.

---

## 🗂️ How to Add Your Real Photos

Simply drop your photos into this folder (`c:\Pratiksha website\assets\images\`) using the following recommended filenames:

| Photo Type | Suggested Filename | Format | Description |
| :--- | :--- | :--- | :--- |
| **Dr. Pratiksha Barge's Photo** | `dr-pratiksha.jpg` | `.jpg` or `.png` | Professional portrait / lab coat photo of Dr. Pratiksha Barge. Will appear in the Hero and "Meet Dr. Pratiksha" sections. |
| **Clinic Operatory / Interior** | `clinic-operatory.jpg` | `.jpg` or `.png` | Photo of the clinic interior, dental chair, or consultation area. |
| **Clinic Reception / Lounge** | `clinic-reception.jpg` | `.jpg` or `.png` | Waiting area, reception desk, or entry lounge. |
| **Smile Makeover Before Photo** | `teeth-before.jpg` | `.jpg` or `.png` | Patient smile before cosmetic / alignment / whitening treatment (for the interactive slider). |
| **Smile Makeover After Photo** | `teeth-after.jpg` | `.jpg` or `.png` | Patient smile after treatment showing transformed teeth. |
